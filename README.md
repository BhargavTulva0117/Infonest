# InfoNest — The Social Knowledge Cosmos 🌌

> **Coursera depth · Instagram velocity · Lavish Cyber-Luxury UI**

InfoNest is a premier knowledge-sharing platform that unites the structured, milestone-driven learning of **Coursera** (video masterclasses, syllabus breakdowns, quizzes, goal roadmaps) with the creator-first feed and rapid viral engagement of **Instagram** (visual infographics, micro-lecture reels, thought drops, creator stories, likes, and comments).

---

## ✨ Features Highlight

### 1. The Nest Feed (Instagram Social Experience)
- **Creator Stories Bar**: Instagram-style story bubbles for quick micro-insights (System design tips, GLSL shader formulas, reasoning LLM flashcards) with full-screen viewer and animated progress bars.
- **Multi-Format Technical Drops**:
  - **Visual Carousels**: Multi-slide infographics with slide counters and swipe navigation.
  - **Lecture Video Reels**: Interactive video container with play/pause, timestamp scrubber, speed control, and direct expand into Coursera mode.
  - **Thought Drops**: Micro-articles with syntax-highlighted code snippets and numbered takeaways.
  - **Roadmap Embeds**: Interactive roadmap cards with milestone progress and 1-click **Adopt to My Goals** button.
- **Interactive Social Actions**: Animated Like button with sound, nested Q&A comments drawer, share with toast, and creator bookmarking.

### 2. Coursera-Style Masterclass Vault & Lecture Player
- **Curriculum Navigation**: Module and lecture breakdown with duration and completion checks.
- **Executive Instructor Notes**: High-density architectural summaries alongside lectures.
- **Resource Downloads**: PDF slides, cheatsheets, and direct GitHub repo links.
- **Knowledge Checkpoints**: Multiple-choice mini-quizzes with instant validation and confetti celebrations.

### 3. Interactive 3D Visualizations (Three.js)
- **3D Knowledge Core Orb**: An interactive glowing polyhedron with orbital neon rings and floating star particles that responds to mouse cursor tilt and hover acceleration.
- **3D Roadmap Constellation**: Interactive 3D milestone graph plotted across space connected by glowing energy conduits. Clicking any node selects and inspects that milestone.
- **3D Holographic Creator Pass**: Physics-based 3D tilt card with dynamic light glare and iridescent sheen.

### 4. Procedural Tactile Audio Engine (Web Audio API)
- No external audio dependencies or broken URLs! Uses synthesized sound nodes:
  - **Tactile Click**: Crisp mechanical switch click for buttons and tabs.
  - **Reward Pop**: Resonant harmonic pop for likes and bookmarks.
  - **Futuristic Chime**: C-major arpeggio for notifications and comments.
  - **Triumph Fanfare**: Majestic celebratory chord with confetti for completed milestones.
  - **Ambient Space Drone**: Toggleable soothing ambient cosmic soundscape with animated audio wave equalizer in the navbar.
  - **Mute / Unmute Toggle**: Master switch to control sound effects.

### 5. Seamless Role Switching: Learner ↔ Creator
- **Learner Mode**: Feed, Explore Cosmos, 3D Roadmaps, Coursera Vault, and Goal Tracking.
- **Creator Mode**: Unlocks the **Creator Studio Modal** (publish Carousels, Video Lectures, Thoughts, or Roadmaps with live previews) and the **Creator Analytics Dashboard** (watch time, active students, and Knowledge Tokens).

## 🚀 Running the Project

### Prerequisites
- Node.js (v18 or v20+)
- npm or pnpm

### Quick Start
```bash

cd "C:\Users\bharg\.gemini\antigravity\scratch\infonest"

# Start the Vite development server
npm.cmd run dev
```

Open your browser at:
👉 **`http://localhost:3000`**

```bash
npm.cmd run build
```
